## Project Name: Using simple CNN model to classify the direction of tabletennis table
## Purpose
The purpose of this project is to assist in generating a large amount of training data. The training data comes from table tennis broadcast videos, which generally feature two main camera angles: one where the table appears vertical in close-up shots and another where the table appears horizontal in standard shots. This model enables the separation of these two scenarios.
## Model
- ResNet18
- Mobilenet
- VGG16
